## 🎯 What Makes Enhanced/Ultra Special?

### **Fibonacci+ ⚡ Enhanced** vs Regular Modes:

1. **Strategic Planning** - See next 1-3 pieces to plan ahead
2. **Hold Mechanic** - Save a piece for later (like Tetris)
3. **Customizable Experience** - Adjust to your preferences
4. **Better Audio** - Volume control for different environments
5. **Visual Feedback** - Floating scores, better animations
6. **Settings Persistence** - Your preferences are saved

### **Fibonacci Ultra 🔥** Adds:

7. **Horizontal Fibonacci Merges** - Double the merge opportunities!
   - Example: `[2][3]` horizontally → merges to `[5]`
   - Example: `[1][1]` horizontally → merges to `[2]`
   - Creates insane combo chains!
   - Much faster gameplay
   - Highest difficulty

## 🔧 Technical Details

**Enhanced/Ultra Features Use:**
- `game/GameConstants.js` - Shared constants
- `game/GameAudio.js` - Volume-controlled audio
- `game/GameLogic.js` - Enhanced merge logic
- `game/GameLogicUltra.js` - Ultra horizontal Fibonacci merges
- Modular, clean code architecture
- LocalStorage for settings persistence
- Separate stats tracking per mode

**Regular Modes:**
- Single-file components
- Basic audio (no volume control)
- Standard merge logic
- No settings customization
